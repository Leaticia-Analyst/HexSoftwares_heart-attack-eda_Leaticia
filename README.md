# HexSoftwares - Heart Attack EDA Project
## Project Overview
This project performs Exploratory Data Analysis (EDA) on a heart attack dataset to understand cardiovascular risk factors and patient characteristics.
The dataset contains 1000 patient records including demographic, clinical, and treatment-related variables.

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Data Cleaning & Validation
- Statistical Summary Analysis
- Correlation Heatmap
- Distribution Analysis (Histograms & Boxplots)
- Categorical Variable Analysis

## Key Insights
- Balanced gender representation.
- Average patient age around 60 years.
- Cholesterol and blood pressure values within realistic clinical ranges.
- No strong linear correlation between major numerical risk factors.

## Future Improvements
- Build predictive machine learning models.
- Perform classification for heart disease risk assessment.
